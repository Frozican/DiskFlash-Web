Flash drives.

Prepare an image, select a physical disk, and write it through an explicitly installed local helper. Supports USB drives and hard drives on Linux and Windows.

!
Disk writes permanently erase data

GitHub Pages alone cannot write to ordinary disks. For real flashing, download and run the local helper on your computer. It refuses boot/system disks, read-only disks, mounted Linux disks, and images larger than the target. Always double-check the selected disk.
